# Level Up Store 🛒

A simple and responsive shopping cart website built using HTML, CSS, and JavaScript.
> **Live Demo:** [Click here to explore the store](https://modibodi057-collab.github.io/level-up-store/)

---

## ✨ Features

- Responsive design  
- Store page with products  
- Add products to cart  
- Remove products from cart  
- Update quantity dynamically  
- Automatic total price calculation  
- Clean and simple UI  

---

## 🛠 Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
